# Retrospectives

A retrospective records how the agent environment should change after a step or session. It is not a review verdict
and not a blame record.

- Create one from [`_template.md`](_template.md) when a step closes or a session exposed avoidable friction.
- Name it `YYYY-MM-DD-<slug>.md`.
- Give every candidate an owner and a next action.
- Put process changes on a normal `docs/<slug>` branch with owner approval.
- Link the retro from the step page or the status dashboard.

The normative discipline is in
[`docs/development/retrospectives.md`](../../development/retrospectives.md).
