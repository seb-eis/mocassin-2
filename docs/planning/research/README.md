# Research notes

Research notes hold cited answers to questions that needed external reading. They are evidence, not design docs.

- Create a note on demand from [`_template.md`](_template.md).
- Name it `YYYY-MM-DD-<slug>.md`.
- Link it from the step page, design record, or review/audit record that uses it.
- Keep every non-obvious claim tied to a primary source, with version and section.
- Do not edit an earlier note to change its conclusion; add a new note or append a dated update.

The normative discipline is in
[`docs/development/research.md`](../../development/research.md).
