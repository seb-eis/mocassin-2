# Prototypes

A prototype is throwaway code built to answer one design question. The decision is the deliverable; the code is
discarded or parked.

- Create a brief on demand from [`_template.md`](_template.md).
- Name it `YYYY-MM-DD-<slug>.md`.
- Put the prototype itself under the gitignored `.tmp/prototypes/`, `/home/node/tmp`, or a clearly named throwaway
  branch. Never a step, feature, or `main` branch.
- Record the question, the answer, the decision, and where the decision lives.
- Delete the prototype when the question is answered, or park the branch and link it from the brief.
- Never copy prototype code into production; rewrite the validated decision under the normal design, TDD, and review
  process.

The normative discipline is in
[`docs/development/prototypes.md`](../../development/prototypes.md).
