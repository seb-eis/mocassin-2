# Examples and Publications

Example projects and publication references are added as the model and solver features land.

## Planned examples

- Reduced ceria: oxygen-vacancy migration and polaron hopping.
- Yttrium-doped barium zirconate: proton/vacancy transport with hydration.
- Vehicle and interstitialcy mechanisms.

## Citation

The original MOCASSIN release paper is:

> S. Eisele and S. Neitzel-Grieshammer, *J. Comput. Chem.* **2021**, 42, 737–748.
> <https://doi.org/10.1002/jcc.26418>

The reimplementation targets the scientific concepts and numerical behaviour of the original, not its source
code.
