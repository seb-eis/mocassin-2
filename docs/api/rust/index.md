# Rust API

This is a placeholder for the generated rustdoc reference. The published path is `/api/rust/`.

`cargo doc --manifest-path src/rust/Cargo.toml --workspace --no-deps` writes HTML to `target/doc/`; the documentation build copies it into
`site/api/rust/`. Public items require doc comments, and missing docs are denied in CI as the workspace
matures. Generated output is not committed.

See the [API overview](../index.md) for the other language references.
