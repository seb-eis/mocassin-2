# .NET API

This is a placeholder for the generated DocFX reference. The published path is `/api/dotnet/`.

DocFX reads the .NET assemblies and XML documentation from `src/dotnet/` and writes HTML to
`artifacts/docfx/`; the documentation build copies it into `site/api/dotnet/`. The generated output is not
committed.
