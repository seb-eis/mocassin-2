# .NET API

This placeholder is only used by a narrative-only build before DocFX output exists. The published site links
directly to the first .NET API content page, `api/Mocassin.Core.CoreModule.html`, and `/api/dotnet/` is a
generated redirect to that page.

DocFX reads the .NET assemblies and XML documentation from `src/dotnet/` and writes HTML to
`artifacts/docfx/`; the documentation build copies it into `site/api/dotnet/`. Generated output is not
committed.

See the [API overview](../index.md) for the other language references.
