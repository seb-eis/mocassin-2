# Step 11 cluster expansion sample

This sample builds the Step 11 amendment-2 `.msl` fixture in
[`tests/contracts/packages/step-11-amend-2/`](../../tests/contracts/packages/step-11-amend-2/). It is derived
from [`samples/ceria/ceria.mocprj`](../ceria/ceria.mocprj) and keeps the primary two-member cluster:

- centre site `018f4c9a-7f6b-7c3a-9d2e-1a2b3c4d5f07` (`O transition`), offsets `[-0.25, 0, 0]` and
  `[+0.25, 0, 0]`;
- the stable oxygen site and both `O`/`Vc` particle sets, so all eight raw member tuples are allowed;
- one KMC oxygen migration and one job at 2×2×2.

The structure is **origin-shifted** so the cluster centre lies at the origin of the P-1 (space group 2) cell.
The P-1 inversion then fixes the centre and swaps the two member slots, exactly the reduction that produces
six canonical orbits from eight raw tuples. The compiled particle order is `0 = void, 1 = Ce, 2 = O, 3 = Vc`;
table 0 stores codes `8322, 8323, 12418, 12419, 12482, 12483` and the expansion map resolves the two
non-canonical codes `8386 → 12418` and `8387 → 12419`.

The sample uses a translated P-1 representation rather than the full space-group-225 ceria cell so the fixture
stays compact and the KMC path is unambiguous. The cluster geometry, site identities, offsets, and the eight raw
codes are the same as the primary ceria cluster.

## Build

```sh
dotnet run --project src/dotnet/Mocassin.Cli -- \
  build samples/step-11-cluster-expansion/step-11-cluster-expansion.mocprj -o /tmp/step-11-amend-2.msl
```

The committed fixture is regenerated by the real writer with a fixed timestamp; see the fixture README. Do not
hand-edit the package.
