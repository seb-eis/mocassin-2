# Samples

Canonical example projects used by tutorials, CLI checks, and parity tests.

| Directory | Purpose |
| --- | --- |
| [`blank/`](blank/README.md) | Minimal project skeleton for new users and tests |
| [`ceria/`](ceria/README.md) | Reduced-ceria KMC/MMC reference project |

Additional barium-zirconate, vehicle, and interstitialcy samples are added by the steps that implement the
corresponding model features. Sample projects must use the current `.mocprj` schema; legacy formats are not
supported.
