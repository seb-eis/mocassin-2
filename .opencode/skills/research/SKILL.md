# Research

Read [`docs/development/research.md`](../../../docs/development/research.md) and create the note from
[`docs/planning/research/_template.md`](../../../docs/planning/research/_template.md).

Answer one bounded question from primary sources: official documentation, specifications, source code, first-party
APIs, release notes, and standards. Use the web search and fetch tools for the sources when they are available, then
read the relevant sections instead of relying on a snippet. Cite every non-obvious claim with a URL, version, and
section.

Separate fact from interpretation. State confidence and what was not checked. Redact secrets, private URLs, and
personal data. Save the note under `docs/planning/research/` and link it from the step page or the record that uses
it. Do not turn the task into a broad crawl, and do not research a question the repository already answers.
